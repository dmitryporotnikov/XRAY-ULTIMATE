# Audit Report Export Engine Specification

## Overview

**XRAY ULTIMATE** includes an enterprise-grade reporting engine capable of serializing the entire system state into three distinct formats:
1. **Interactive HTML Report (`.html`)**: Responsive dark/light audit document with KPI metric cards, grouped property tables, and print optimization.
2. **Machine-Readable JSON (`.json`)**: Formatted hierarchical JSON structure for automated security scanners and CMDB ingestion.
3. **Plain Text / Markdown (`.txt`)**: Formatted ASCII report designed for ticketing systems, Jira, GitHub issues, and terminal inspection.

---

## 1. Native Elevated File Dialog Architecture (`NativeFileDialog.cs`)

### The UIPI & Elevated UAC Challenge
When an application runs unpackaged with administrative privileges (`requireAdministrator`), Windows App SDK's standard `Windows.Storage.Pickers.FileSavePicker` fails or throws `COMException` (Catastrophic Failure / Access Denied). This occurs because User Interface Privilege Isolation (UIPI) blocks cross-integrity COM communication between the elevated process (High Integrity) and the interactive medium-integrity shell broker (`explorer.exe`).

### The Solution: In-Process Win32 COM `IFileSaveDialog`
XRAY ULTIMATE implements `NativeFileDialog.cs`, which invokes `CLSID_FileSaveDialog` (`C0B4E2F3-BA21-4773-8DBA-335EC946EB8B`) directly in-process:

```csharp
[ComImport]
[Guid("42f85136-db7e-439c-85f1-e4075d135fc8")]
[InterfaceType(ComInterfaceType.InterfaceIsIUnknown)]
private interface IFileSaveDialog
{
    [PreserveSig]
    int Show([In] IntPtr parent);
    void SetFileTypes([In] uint cFileTypes, [In, MarshalAs(UnmanagedType.LPArray)] COMDLG_FILTERSPEC[] rgFilterSpec);
    void SetFileName([In, MarshalAs(UnmanagedType.LPWStr)] string pszName);
    void SetDefaultExtension([In, MarshalAs(UnmanagedType.LPWStr)] string pszDefaultExtension);
    void GetResult([MarshalAs(UnmanagedType.Interface)] out IShellItem ppsi);
    ...
}
```

- **In-Process Server (`shell32.dll`)**: Runs completely within the application's process boundary, eliminating any cross-process broker dependency.
- **Fail-Safe Fallback**: If COM initialization encounters any environmental constraint, it falls back to Win32 `comdlg32.dll` (`GetSaveFileNameW`).
- **Parent HWND Binding**: Correctly modal to `WindowHelper.MainWindowHandle`.

## 2. Interactive HTML Report Structure

Generated by `ReportExportService.ExportToHtmlAsync`:
- **Responsive Layout**: Pure CSS without external CDN dependencies (works completely offline and in air-gapped environments).
- **Summary Header**: Computer Name, OS Version, Uptime, Engine Build, and Audit Generation Timestamp.
- **Executive KPI Cards**: Primary Processor, Memory Utilization %, Active GPU Accelerator, and Cloud Identity Join Status.
- **Detailed Grouped Property Tables**: Structured matrices for CPU, RAM, Motherboard, GPU, Storage, Network, Battery, Security/TPM, Filter Drivers, and ACPI.
- **Software Catalog**: Alphabetical listing of all installed 64-bit and 32-bit software packages with versions and publishers.
- **Raw Diagnostic Logs**: Collapsible formatted code box containing raw `dsregcmd /status` telemetry.
- **Print Optimization (`@media print`)**: Automatically hides dark backgrounds, switches to high-contrast ink-saving typography, and prevents awkward table page breaks.
